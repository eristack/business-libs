# @eristack/local-monorepo-versioning

Private **product** monorepos: one root release counter, independent package semver, append-only `releases[]` history — without Changesets or npm publish.

Start with [Getting started](./getting-started.md). Published `@eristack/*` libraries (including this repo) still use **Changesets** — see `@eristack/ai-knowledge#dev-conventions`.
