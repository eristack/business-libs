# @eristack/file-manager

Headless file uploads for Eristack apps: **S3** (presigned PUT/GET), server uploads, canonical **`FileRef`** for DB columns, Drizzle metadata store, Express REST router, client + React dev tools.

```bash
pnpm add @eristack/file-manager @eristack/file-manager/s3
```

Docs: [`docs/getting-started.md`](./docs/getting-started.md) · Intent: `file-manager-core`, `file-manager-adapters`.
