# @eristack/oauth

OAuth2 **client** (`/client`: 17+ IdP drivers — Google, Microsoft, GitHub, Apple, Okta, Auth0, Keycloak, …) and **provider** (`/provider`: authorization server for integrators). App sessions still use [`@eristack/jwt-auth`](../jwt-auth).
