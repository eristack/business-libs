# @eristack/fraction

Exact **rational** numbers as reduced fractions (`num` / `den` strings). BigInt normalization — no float literals.

- Parse `3/4`, mixed `1 1/2`, integers
- Exact `+ − × ÷` and compare
- `approximateFraction` / `convergentFraction` for decimals and irrationals (bounded denominator)

```bash
pnpm add @eristack/fraction
```
