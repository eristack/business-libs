# API reference

| Export | Description |
| --- | --- |
| `normalizePerson` / `normalizePersonName` | Canonical person |
| `formatPersonDisplay` | Display string |
| `formatPersonSortable` | "Family, Given" |
| `GENDER_IDENTITIES` | Allowed gender values |
| `normalizeGenderIdentity` | Parse gender string |
| `PersonParseError` | `code: PERSON_PARSE` |
| `personSchema` | `@eristack/person/zod` |
